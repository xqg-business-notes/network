# 平台与安装条件

本 Skill 需要能读取 `SKILL.md` 及配套参考、运行 Python 3、联网访问公开 HTTPS 服务，并保存本地连接标识的 AI 工具。不同系统先检查可用 Python 命令，脚本路径以实际安装目录为准，遵守宿主权限流程。

Codex 已有安装与使用记录。WorkBuddy 官方支持技能与脚本，用户反馈本项目可安装使用，但不是各系统和功能全部通过测试的承诺。Kimi Code CLI 官方支持 Agent Skills，本项目尚未完成实测。不能由 WorkBuddy 可用推断普通 Kimi、DeepSeek、豆包聊天入口也能安装；也不能仅根据所用模型判断宿主能力。

官方仓库：https://github.com/xqg-business-notes/network 。安装目录为 `skills/xqg-business-network`。先检查运行环境，再运行 `scripts/network_client.py status`；只有真实成功回执才说明连接正常。安装完成、连接成功和实际查询成功分别报告，不制造虚构搜索、档案或接待记录来验收安装。

无执行或联网能力时，如实说明无法使用完整人脉查询，可按用户意愿整理需求草稿，不声称已经搜索或登记。可建议换用满足条件的 AI 工具，不要求普通用户配置服务器、提供管理员连接或重新生成标识。

定时雷达另外需要宿主正式调度及通知能力，只有用户明确要求并实际创建成功后才称已开启。Skill 不自动获得其他聊天、跨会话记忆或后台运行权限。反馈可联系小强哥微信 xqiangga。
