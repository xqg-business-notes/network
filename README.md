# 小强哥 Business Network

**创业做生意，缺什么资源？说出你的需求，帮你找到能合作的人。**

当前版本：**0.4.5**。免费使用，面向全行业、已经使用 Codex 的创业者。

## 找到生意上需要的合作资源

找供应商、找销售渠道、找专业服务，或者找有明确需求的潜在客户。

带着问题或需求来找，AI 会按你的需求进行语义搜索，再核对业务并分组展示相关人选，列出简短匹配理由，再根据你的补充匹配更合适的资源。想联系哪一位，由小强哥通过微信协助引荐。

例如：“我开了一家食品公司，想找包装供应商。”“我提供企业培训，想找有明确培训需求的客户。”

推荐卡片先显示编号，再显示加星号的称呼、业务和资源。真实姓名由后台保留供小强哥核对引荐。

### 也可以留下资源档案，让别人找到你

介绍你的产品、业务、服务或公司，AI 帮你整理成资源档案。保存前可核对本人完整档案及脱敏公开预览。你确认后，系统保存并生成正式编号，再输出一份方便复制的完整档案。

**保存后，请加小强哥微信，把整张档案发给他。微信确认后才开放匹配**，方便其他创业者有相关需求时，小强哥能及时联系你、协助对接。

网络正在持续扩充，早一点留下资源档案，就能早一点参与合作匹配。

```text

```

安装后直接说需求即可，无需申请激活或配置服务器：

```text
用 xqg-business-network 帮我找合作。我目前做的是……
```

已经安装过，直接对 Codex 说：

```text
帮我更新小强哥 Business Network 到官方最新版，保留原有连接和我的资料。
```

每次开始使用时，助手会检查是否有新版，有优化更新就简短提醒。说“帮我更新”即可由助手协助升级。后台新增资源会直接用于查询。不会因为有普通新版就突然停止旧版查询。

按合作需求匹配人选，不提供整份通讯录或全库批量导出。
