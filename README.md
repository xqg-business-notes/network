# 小强哥商业人脉

Business Network · 小强哥商业笔记

**说出你的业务和需求，寻找生意上可能合作的人。**

找供应商、销售渠道、专业服务，或者有明确需求的潜在客户。商业人脉会根据你的需求查询已有资源，说明人选为什么相关，再根据你的补充继续筛选。想联系谁，由小强哥通过微信协助引荐。

例如：

> 我做食品生意，想找能做小批量定制的包装供应商。

> 我提供企业培训服务，想找有明确培训需求的客户。

匹配范围取决于现有资源和对方实际情况，不保证每个行业都有合适人选，也不保证达成合作。目前查询与微信引荐服务免费，双方后续合作的费用自行商议，无须加入付费社群。

## 安装与开始使用

在支持 Skill、脚本执行和联网的 AI 工具中，把下面这句话发给安装助手：

```text
请从 https://github.com/xqg-business-notes/network 安装 skills/xqg-business-network 目录中的 Skill，检查运行条件，并确认服务连接是否正常。
```

Codex 可使用；WorkBuddy 支持技能安装，已有用户反馈可使用小强哥的 Skill。其他工具先看[兼容与安装条件](docs/compatibility.md)。只有普通对话功能的窗口不能仅靠这句话完成安装。

安装后说：“用小强哥商业人脉帮我找合作，我的需求是……”即可。也可以下载仓库，把 `skills/xqg-business-network` 文件夹按你的 AI 工具说明导入。

**在 GitHub 搜索：`xqg-business-notes/network`。** 认准发布者 `xqg-business-notes`（小强哥商业笔记）。搜索未及时收录时，直接打开上面的地址。

已安装的用户可以说：“按这个新地址更新小强哥商业人脉，保留原有连接和资料。”旧版更新遇到问题时，让安装助手按[更新说明](skills/xqg-business-network/references/updates.md)处理，无须先删除原 Skill 或重新登记。

## 也可以让别人找到你

把公司介绍、产品手册或服务案例交给你的 AI，它会根据已读取的材料，整理公司、OPC 或个人的产品服务、案例和需求档案。图片、Word、PDF、表格及网站的读取能力以你使用的 AI 工具为准。

可以保存经你确认的案例介绍，以及公开的图片、视频、网页和文档链接，方便合作方进一步了解。当前版本不上传托管原始文件；链接不等于文件备份。保存前会展示完整草稿和其他用户能够看到的内容，供你核对和确认。已有档案合并更新，沿用原编号。

确认保存后，**添加小强哥微信，把完整档案发给他；经微信确认可联系后，才会开放匹配。** 找资源不要求先登记自己。

## 联系与交流记录

服务需要联网，并设有查询额度；按具体需求匹配，不提供整份通讯录下载。
